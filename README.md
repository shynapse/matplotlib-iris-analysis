# Iris Data Visualization with Matplotlib

A practical data visualization project using the Iris dataset, Pandas, and Matplotlib.

## Project Overview

This project explores the famous Iris dataset through multiple visualization techniques. The goal is to understand feature distributions, compare flower species, and practice creating different types of plots using Matplotlib.

## Technologies Used

* Python
* Pandas
* Matplotlib

## Dataset

The Iris dataset contains measurements from three species of iris flowers:

* Setosa
* Versicolor
* Virginica

### Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## Implemented Visualizations

### 1. Histogram

Distribution of petal length for each flower species.

### 2. Line Plot

Comparison of average feature values for each species.

### 3. Bar Chart

Average petal length grouped by flower species.

### 4. Pie Chart

Percentage distribution of flower species.

### 5. Scatter Plot

Relationship between petal length and petal width with different colors for each species.

### 6. Subplots (2×2)

Histograms of all four numerical features displayed in a single figure.

### 7. Box Plot

Distribution, spread, and potential outliers for all numerical features.

## Learning Outcomes

This project helped practice:

* Data visualization principles
* Exploratory Data Analysis (EDA)
* Feature comparison
* Distribution analysis
* Working with Matplotlib figures and axes
* Creating subplots
* Understanding box plots and outliers
